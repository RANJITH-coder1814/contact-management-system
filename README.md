# contact-management-system
A simple console-based Contact Management System built using Python that allows users to add, view, search, update, and delete contacts with file-based storage.

A simple console-based Contact Management System built using Python.

## 🚀 Features
- Add new contacts
- View all contacts
- Search contact by name
- Update contact details
- Delete contact
- File-based storage using JSON

## 🛠 Technologies Used
- Python
- JSON (File Handling)

## ▶️ How to Run

1. Clone the repository
2. Navigate to the project folder
3. Run:

python main.py
